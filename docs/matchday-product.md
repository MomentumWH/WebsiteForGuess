# MATCHDAY · 赛事预测工作台

## 产品流程

1. 赛事总览：默认关注阿森纳，筛选英超、欧冠，查看下一场与待预测比赛。
2. 比分预测：输入主客队 0–20 的整数比分、信心程度和预测理由；允许开赛前修改或确认撤回。按北京时间展示赛程。
3. 开赛锁定：以开球时间锁定预测；未预测的历史比赛不可补录预测。
4. 赛后复盘：常规时间（含补时，不含加时及点球）的实际比分对比个人预测，区分比分命中、仅胜平负命中、未命中、未预测。
5. 数据统计：只计入有预测且已完赛的场次；待赛预测不进入命中率分母。比分命中同时属于胜平负命中。

## 第一版数据边界

赛程与比分已接入 Premier League 和 UEFA 官网自身使用的数据接口，详见 [官方数据接入文档](official-football-api.md)。页面显示各来源同步状态与成功更新时间，失败时保留缓存，不回填虚构赛事。个人预测使用独立本地浏览器存储，可导出；原有演示记录保留但不参与真实赛事统计。正式账号服务仍需由服务器验证开赛锁定时间与保存记录，不能依赖客户端锁定。

## 视觉与组件

浅灰白画布、深球场绿、薄荷色选中态、阿森纳红；固定侧栏与宽内容区，球场照片横幅，重点赛事与数据卡并列，响应式移动布局。

- MatchdayWorkspace：组合导航、筛选、预测弹窗与各内容区。
- MatchHero：球场横幅及下一场比赛；接收 match / prediction，发出 predict / navigate。
- MatchList：赛事筛选和卡片；接收 matches / predictions，发出 predict / review，使用 league、onlyArsenal 双向绑定。
- ReviewTable：已完赛结果与预测对比；接收 rows，发出 detail。
- StatsPanel：派生统计和分赛事命中率；接收 stats，不保存独立统计状态。
- PredictionDialog：比分表单与只读复盘；接收 match / prediction，发出 save / close。
- TeamBadge / AppIcon：通用队徽和线条图标。
- usePredictions：本地存储校验、保存、开赛校验与统计计算，显式更新动作。

父组件持有筛选与导航状态；子组件通过类型明确的 props / emits 通信。统计统一从比赛与预测派生，不手工维护。
